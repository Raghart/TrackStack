# Cómo lo separaría yo
README.md (se queda corto, ~1 scroll de pantalla):

- Badges + título + 1 línea de pitch

- Live demo link

- 1 screenshot principal

- Stack técnico en bullets cortos, no párrafos (NestJS, GraphQL, PostgreSQL+pgvector, Elasticsearch, Jest (196 tests, 90% coverage), Playwright E2E)

- Quick Start / instalación

- Link: "📖 Ver documentación completa en docs/"

# docs/ (ahí sí todo el detalle):

- docs/features.md → todas las secciones de "Usage" con screenshots

- docs/architecture.md → el detalle técnico de cada tecnología, por qué la elegiste, decisiones de diseño

- docs/motivation.md → la historia personal (válida, pero no es lo primero que un evaluador técnico necesita)
